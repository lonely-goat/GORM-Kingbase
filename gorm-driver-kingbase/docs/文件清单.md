# 保留文件清单

本清单中的路径相对交付仓库的 `gorm-driver-kingbase/` 模块目录。完整交付还包括根目录说明、统一测试入口、`third_party/gokb/` 及其来源记录，见[仓库根目录说明](../../README.md)。生产文件负责运行行为；测试、脚本和测试源码归档负责验证与复现，不因它们不参与业务运行而删除。

## 生产实现：13 个 Go 文件

| 文件 | 用途 |
|---|---|
| [kingbase.go](../kingbase.go) | Config、Dialector、Open/New；连接建立、模式探测、连接归属保护、回调注册、Migrator 工厂、保存点 |
| [mode.go](../mode.go) | auto/mysql/oracle 定义、配置归一化及严格模式解析 |
| [quote_bind.go](../quote_bind.go) | 按模式生成占位符、引用标识符、解释日志 SQL |
| [clause.go](../clause.go) | 双模式冲突处理、空列 VALUES 和 Oracle 分页 |
| [mysql_types.go](../mysql_types.go) | MySQL 模式整数、自增、字符串、数值、时间、二进制及自定义类型映射 |
| [oracle_types.go](../oracle_types.go) | Oracle 模式类型、整数 identity、时间精度及自定义类型映射 |
| [oracle_names.go](../oracle_names.go) | Oracle 目录名归一化、结果列标签及嵌套 JOIN 标签映射 |
| [map_returning.go](../map_returning.go) | map 切片创建包装及常规 RETURNING 结果归并 |
| [errors.go](../errors.go) | gokb SQLSTATE 转为 GORM 标准错误 |
| [migrator.go](../migrator.go) | schema 定位、表列索引约束操作、类型别名及迁移元信息入口 |
| [migrator_columns.go](../migrator_columns.go) | 列属性和主键/唯一约束读取、元信息补齐、默认值归一化 |
| [migrator_mysql.go](../migrator_mysql.go) | MySQL 模式列目录 SQL，补足 identity、字符长度和注释 |
| [migrator_oracle.go](../migrator_oracle.go) | Oracle 模式列目录 SQL，读取 is_identity 等属性 |
